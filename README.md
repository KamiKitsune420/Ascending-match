## 1. What Is This?

**Ascending Match** is an innovative audio-first number puzzle game that challenges your mental math and strategic thinking. Your mission is to arrange randomly generated numbers in ascending order through strategic swapping, all while racing against the clock.

### Core Concept

- **Objective**: Arrange numbers from smallest to largest
- **Method**: Mark two numbers and swap their positions
- **Challenge**: Beat the timer while maintaining accuracy
- **Progression**: Each round introduces new difficulty mechanics

### What Makes It Special

- **Full Audio Accessibility**: Screen reader compatible with spatial audio positioning
- **Progressive Difficulty**: From simple integers to complex decimals and negative numbers
- **Competitive Scoring**: Track your accuracy and compete against yourself
- **Immersive Experience**: Rich audio feedback and atmospheric music

## 2. Getting Started

### First Launch

**On desktop (Windows/Mac/Linux):**
1. Run the game executable
2. Wait for the title audio sequence
3. Press **Enter** when prompted to access the main menu
4. Use **Up/Down arrows** to navigate menus
5. Press **Enter** to select options

**On mobile (iOS/Android):**
1. Launch the app
2. Wait for the title audio sequence
3. **Double tap** when prompted to access the main menu
4. **Swipe up/down** with one finger to navigate menus
5. **Double tap** to select options

### Audio Setup

The game automatically detects your audio setup, but you can customize:

- **Output Device**: Switch between audio devices
- **Volume Controls**: Adjust game music and menu sounds
- **Speech Mode**: Choose between screen reader or built-in TTS

## 4. Gameplay Manual

### Game Setup

Each round begins with:

- **Random Number Generation**: Based on current difficulty level
- **Time Allocation**: Varies by round (120s early, 45s later rounds)
- **Audio Announcement**: "Round X. Numbers to arrange: Y"
- **Special Announcements**: New difficulty types introduced

### Core Controls

**Navigation**
- **Left/Right Arrows**: Move through the number list
- **Home**: Jump to first number
- **End**: Jump to last number
- **Spatial Audio**: When enabled, hear your position in stereo

**Number Management**
- **Spacebar**: Mark/unmark numbers for swapping
- **Two Marked Numbers**: Automatically swap positions
- **Audio Feedback**: "Marked", "Unmarked", "Swapped"

**Information & Help**
- **H Key**: Hint system (5-second cooldown)
  - "X numbers are in the correct spot"
  - "Y are out of place"
- **T Key**: Time remaining announcement
- **P Key**: Pause/resume game

**Audio Controls**
- **Page Up/Down**: Adjust game music volume (in-game)
- **Volume Range**: -50 (quietest) to 0 (loudest)
- **Real-time Adjustment**: Immediate audio feedback

**Game Management**
- **Escape**: Return to main menu (loses current progress)
- **Game Over**: Automatic when time expires

### Swap Strategy

1. **Listen to Numbers**: Navigate and identify positions
2. **Mark First Number**: Press space on your first choice
3. **Navigate to Second**: Move to the number you want to swap with
4. **Mark Second Number**: Press space again to trigger swap
5. **Verify Result**: Numbers are automatically read aloud
6. **Repeat Process**: Continue until fully sorted

### Win Condition

- **Success**: All numbers arranged in ascending order
- **Feedback**: "Round complete!" audio cue
- **Progression**: Automatic advance to next round
- **Music Enhancement**: Pitch increases with each round

## 5. Touch Controls (iOS & Android)

On mobile platforms the game automatically speaks gesture instructions instead of keyboard instructions. Every keyboard shortcut has a touch gesture equivalent — you never need a physical keyboard.

### Navigation Gestures

| Gesture | Action |
|---|---|
| Swipe left (1 finger) | Move left / previous item |
| Swipe right (1 finger) | Move right / next item |
| Swipe up (1 finger) | Move up in menu |
| Swipe down (1 finger) | Move down in menu |
| 2-finger swipe left | Jump to first number (Home) |
| 2-finger swipe right | Jump to last number (End) |

### Action Gestures

| Gesture | Action |
|---|---|
| Single tap (1 finger) | Mark / unmark a number (Spacebar) |
| Double tap (1 finger) | Confirm / advance dialog (Enter) |
| Triple tap (1 finger) | Copy dialog text to clipboard (C) |
| Single tap (2 fingers) | Go back / exit menu (Escape) |
| Double tap (2 fingers) | Pause / unpause game (P) |

### Information Gestures

| Gesture | Action |
|---|---|
| Long press (1 finger) | Hint — how many numbers are in the right spot (H) |
| Long press (2 fingers) | Announce time remaining (T) |

### Volume & Menu Gestures

| Gesture | Action |
|---|---|
| 2-finger swipe up | Volume up (Page Up) |
| 2-finger swipe down | Volume down (Page Down) |
| Single tap (3 fingers) | Re-read menu title / current item (Tab) |
| Double tap (3 fingers) | Search for a menu item (F3) |

### Tips for Touch Play

- All gestures work in both menus and during gameplay
- The hint long press has a cooldown — you will be told if it is not ready yet
- When two numbers are marked, they swap automatically; no extra confirmation needed
- In dialogs, swipe in any direction with one finger to have the message re-read to you

## 6. Difficulty Progression

### Number Types by Round

**Rounds 1-7: Classic Integers**
- Range: 1-99
- Example: 23, 67, 45, 91, 12
- Time: 120 seconds (rounds 1-6)
- Focus: Learn basic mechanics

**Rounds 8-11: Decimal Introduction**
- Range: 1.0-99.9 (one decimal place)
- Example: 23.5, 67.2, 45.8, 91.1
- Announcement: "New challenge: Decimal numbers introduced!"
- Focus: Precision sorting skills

**Rounds 12-14: Negative Numbers**
- Mix of positive and negative integers (-99 to +99)
- Example: -45, 23, -12, 67, -8
- Announcement: "New challenge: Negative numbers added!"
- Focus: Understanding negative number ordering

**Rounds 15-19: Extended Range**
- Range: 1-999 with negatives
- Example: -456, 123, -789, 345, -67
- Announcement: "New challenge: Larger number ranges!"
- Focus: Mental math with bigger numbers

**Rounds 20-24: Mixed Chaos**
- Combination: integers, decimals, AND negatives
- Example: -123.5, 67, -45.2, 234.7, -8
- Announcement: "New challenge: Mixed number types!"
- Focus: Ultimate mental flexibility

**Round 25+: Precision Challenge**
- High-precision decimals: 12.34, 12.67, 12.89
- Announcement: "Ultimate challenge: Precision decimals!"
- Focus: Extreme attention to detail

### Time Pressure System

- **Rounds 1-6**: 120 seconds
- **Rounds 7-12**: 90 seconds
- **Rounds 13-20**: 60 seconds
- **Round 21+**: 45 seconds
- **Final 20 Seconds**: Clock ticking audio warning

### Quantity Scaling

- **Rounds 1-4**: 5-10 numbers
- **Rounds 5-10**: 10-15 numbers
- **Rounds 11-19**: 15-25 numbers
- **Round 20+**: 30-50 numbers

## 7. Scoreboard System

### Local High Scores

- **Top 10 Leaderboard**: Best performances saved locally
- **Sorting**: By round reached, then by accuracy
- **Persistence**: Encrypted storage in `data/scores.dat`

### Scoring Metrics

**Tracked Statistics**
- **Round Reached**: Highest round completed
- **Total Swaps**: All swap attempts made
- **Correct Swaps**: Swaps that improved sorting
- **Accuracy Percentage**: (Correct ÷ Total) × 100

**Accuracy System**

The game intelligently analyzes each swap:
- **Beneficial Swap**: Increases numbers in correct positions
- **Non-beneficial Swap**: Doesn't improve overall sorting
- **Real-time Tracking**: Updated with every swap attempt

### High Score Process

1. **Game Over**: When time expires
2. **Statistics Display**: Audio presentation of your performance
3. **High Score Check**: Automatic detection if you made top 10
4. **Name Entry**: Audio form interface for player name
5. **Leaderboard**: Score saved and ranked automatically

### Score Display Format

```
1: Kitsune, made it to round 15, with an accuracy of 87.3%
2: Player, made it to round 12, with an accuracy of 92.1%
3: Alex, made it to round 12, with an accuracy of 78.5%
```

### Scoreboard Navigation

- **Browse Scores**: Up/down arrows through leaderboard
- **Detailed View**: Enter on any score for full statistics
- **Clear All**: Option to reset entire leaderboard
- **Return**: Back to main menu

## 10. Tips & Strategies

### Mental Strategies

**Number Analysis**
- **Listen Carefully**: Pay attention to each number's value
- **Decimal Precision**: Note decimal places in advanced rounds
- **Negative Recognition**: Understand negative number positioning
- **Range Awareness**: Know the current round's number range

**Sorting Techniques**
- **Bubble Sort Method**: Work from smallest to largest systematically
- **Pair Comparison**: Compare adjacent numbers for efficiency
- **Anchor Points**: Use correctly positioned numbers as references
- **Progressive Refinement**: Make increasingly precise adjustments

### Time Management

**Speed Strategies**
- **Quick Assessment**: Use hint system (H key) early
- **Focus on Major Errors**: Fix obviously wrong positions first
- **Skip Minor Adjustments**: Don't perfect early in the timer
- **Clock Awareness**: Check time remaining (T key) regularly

**Accuracy Balance**
- **Quality Over Quantity**: Avoid random swapping
- **Think Before Acting**: Plan swaps to improve accuracy score
- **Use Hints Strategically**: 5-second cooldown, use wisely
- **Learn From Mistakes**: Pattern recognition improves over time

### Advanced Techniques

**Audio Positioning (When Enabled)**
- **Stereo Awareness**: Use left-right audio positioning
- **Navigation Efficiency**: "Hear" your position in the array
- **Edge Detection**: Audio cues for array boundaries
- **Spatial Memory**: Remember number positions by audio location

**Accuracy Optimization**
- **Beneficial Swaps**: Focus on swaps that improve overall order
- **Avoid Backtracking**: Don't undo good moves
- **Pattern Recognition**: Learn common sorting patterns
- **Strategic Marking**: Think about second number before marking first

### Competitive Tips

**High Score Pursuit**
- **Consistency**: Better accuracy often beats higher rounds
- **Practice**: Familiarity with number types improves performance
- **Calm Focus**: Don't panic as timer runs low
- **Strategic Restart**: Sometimes starting over is better than poor accuracy

## 12. Troubleshooting

### Audio Issues

**No Sound / Audio Problems**

1. Check Windows audio settings and default device
2. Use Options → Audio Settings → Select Output Device
3. Verify audio device compatibility
4. Restart game after changing system audio settings
5. Try different output devices if available

**Screen Reader Conflicts**

1. Use Options → Speech Settings to toggle TTS modes
2. Ensure screen reader is properly configured
3. Try SAPI mode if screen reader issues persist
4. Check screen reader's application-specific settings

### Gameplay Issues

**Game Freezes / Crashes**

1. Ensure game files are not corrupted
2. Check available system memory
3. Close other audio applications that might conflict
4. Run as administrator if permission errors occur

**Settings Not Saving**

1. Verify write permissions to game directory
2. Check if antivirus is blocking file creation
3. Ensure data/ directory exists and is writable
4. Try running as administrator

**Performance Problems**

1. Close unnecessary background applications
2. Check system audio driver updates
3. Reduce audio quality settings if available
4. Ensure adequate system resources

### Advanced Solutions

**Corrupted Save Data**

- Delete `data/settings.dat` and `data/scores.dat` to reset
- Game will recreate files with default settings
- This will erase all scores and custom settings

**Audio Device Changes**

- Game auto-detects device changes on startup
- Use audio settings menu to manually switch devices
- Restart game if device changes don't register

**Custom Audio Devices**

- Game supports most DirectSound-compatible devices
- USB headsets and audio interfaces work
- ASIO devices may need DirectSound wrapper software
